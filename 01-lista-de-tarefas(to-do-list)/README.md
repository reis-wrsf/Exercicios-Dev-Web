# 📝 Lista de Tarefas (To-Do List)

Um exercício prático de uma lista de tarefas interativa onde o usuário pode adicionar, concluir e excluir itens.

## 🎯 Objetivos do Exercício
* Praticar a manipulação de elementos do HTML via JavaScript (DOM).
* Trabalhar com escuta de eventos (`click`, `submit`).
* Aplicar estilização condicional (alteração de classes CSS via JS ao concluir uma tarefa).

## 🛠️ Tecnologias Utilizadas
* HTML5 (Estrutura semântica)
* CSS3 (Estilização e feedback visual de conclusão)
* JavaScript Vanilla (Lógica de inserção, remoção e toggle de classes)

## 💡 O que aprendi com este projeto
Desenvolver este projeto me ajudou a entender melhor como o JavaScript se conecta com o HTML para criar páginas dinâmicas, especialmente a lógica por trás de gerenciar o estado de um elemento (adicionar/remover classes de estilo baseadas em ações do usuário).
